# 工具、审批与 MCP

内置工具包括 `read_file`、`list_directory`、`search`、`write_file`、`apply_patch` 和 `run_command`。启用工具后，只有能力明确支持工具调用的模型可以使用它们，实际执行仍受审批规则约束。

模型请求发往选定的模型服务，可能包含会话消息、文件内容和工具结果。模型响应、工作区文件和 MCP 工具结果都可能包含外部提供的内容，工具调用由本地规则校验和授权。

## 审批规则

在 TUI 中使用 `/approval ask|auto|full` 切换模式。

| 模式 | 执行方式 |
| --- | --- |
| `ask` | 所有可执行的工具调用都需人工确认。 |
| `auto`（默认） | 自动执行规则允许的操作，其余需人工确认。可在审批支持时授予会话信任。 |
| `full` | 跳过常规审批，包括 MCP 调用，仍保留强制审批和硬编码禁止。 |

硬编码禁止始终生效。工作区外访问、无法检查访问范围的命令和所有 `write_file`、`apply_patch` 写入均需逐次确认，包括在 `full` 模式下。非交互执行会拒绝所有需要审批的调用。

模式和信任保存在运行进程内。信任绑定会话和工具，同一 MCP 工具的后续调用可使用不同参数。新会话拥有独立的信任范围，切换到 `ask` 会清除已有信任。MCP 服务断开、重连或目录变化时会撤销相关信任。

## 文件、补丁与命令边界

- **文件读取和搜索**检查原始及解析后的路径，阻止读取常见凭据文件和带多个硬链接的文件。`.env.example` 可作为模板读取，目录列表和文件名搜索仍可能显示敏感文件的名称。路径规则只能识别已知凭据位置和文件名。
- **新建文件**使用 `write_file(path, content)`，传入完整 UTF-8 文本，可为空，最大 1 MiB。目标须位于当前工作区内，父目录须已存在，路径禁止 `..` 和符号链接目录。目标已存在时返回 `file_exists`。工具先写入并同步暂存文件，再以无覆盖方式原子发布。发布后的校验失败会以 `partial: true` 报告可能已创建的文件。已有文件的局部修改使用 `apply_patch`。
- **补丁**使用普通 unified diff，要求原文精确匹配。工具检查工作区和父目录身份，并通过无覆盖方式安装变更。替换已有文件时，原路径可能短暂缺失。遇到冲突时，无法原位恢复的版本会留在工具报告的暂存位置。进程异常退出留下的 `.daphnis-*.tmp/original` 可用于恢复。多文件写入可能部分生效，具体路径见工具结果。
- **命令**以 argv 执行，并过滤已知凭据环境变量。只有通过参数检查的受信任系统命令 `pwd`、`uname`、`echo` 可以自动放行。`cat`、`ls`、`head`、`tail`、`wc` 等可能访问文件的命令，在 `auto` 和 `full` 下也需确认。审批显示实际执行的 argv。Shell 表达式、内联解释器执行和部分破坏性命令受硬编码限制。
- **进程与文件系统隔离**依赖操作系统。获准运行的程序拥有当前用户的文件和进程权限。外部命令启动时会自行解析路径，同用户的并发进程仍可能替换路径。超时或取消时会尝试终止原进程组并回收直接子进程。脱离进程组的后代和已产生的外部副作用可能保留。

## MCP 配置与生命周期

通过终端入口的 `--mcp-config` 显式指定服务。相对 `cwd` 以配置文件所在目录为准，`env` 将子进程变量名映射到本地环境变量名。

```json
{
  "servers": {
    "demo": {
      "transport": "stdio",
      "command": "python",
      "args": ["server.py"],
      "cwd": "./examples",
      "env": {"SERVICE_API_KEY": "LOCAL_SERVICE_KEY"}
    },
    "remote": {
      "transport": "streamable_http",
      "url": "https://example.com/mcp",
      "auth": {"type": "bearer", "env": "REMOTE_MCP_TOKEN"}
    }
  }
}
```

```sh
uv run --locked daphnis --mcp-config ./mcp.json
```

stdio 程序以当前用户权限启动，应使用可信程序。Streamable HTTP 使用最终端点，远程地址要求 HTTPS，回环地址允许 HTTP。认证可省略，启用时由指定环境变量提供 Bearer Token。MCP Server 决定其内部如何读写文件、使用凭据或访问网络，Daphnis 的审批只控制是否发起工具调用。

`/mcp` 显示服务状态和工具数，`/mcp reconnect <名称>`、`/mcp disconnect <名称>`、`/mcp refresh <名称>` 管理连接和目录。支持工具变更通知的服务可自动刷新，运行中的 Turn 保留开始时的工具定义快照，相关的自动授权仍可被撤销。

对支持工具的模型，首次显式连接新服务时会默认启用发现的工具。从历史恢复的会话和此后新建的会话优先使用保存的选择。恢复会话只恢复启用偏好，MCP 连接需显式配置。掉线和目录变化会保留启用偏好，只有在线且已启用的工具会提供给下一轮。可以在 `/tools` 中取消离线工具的启用偏好，或手动启用目录新增的工具。

MCP 工具的文本和结构化结果共用 64 KiB 的 UTF-8 JSON 预算，预算在 SDK 解码后生效。超限时会标记省略的字段。

## Web 边界

Web 服务仅绑定 `127.0.0.1`，校验请求的 Host、命令和事件连接的 Origin，并要求每次启动生成的访问令牌。浏览器把令牌保存于当前标签页的会话存储。模型连接和密钥由服务端配置，浏览器通过固定命令提交任务和审批，默认审批模式由 Core 决定。

Bridge 对浏览器快照及缓存的调试记录做凭据脱敏，覆盖已配置的模型密钥、Web 令牌和常见凭据格式。实时流式文本在发往浏览器前脱敏。脱敏范围受已知值和匹配规则限制，调试数据仍可能包含工作区内容。Core 历史与事件独立于浏览器脱敏规则。
